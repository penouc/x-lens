X Lens / 推文透镜

少一点噪音。

独立识别推文和详情页评论中的疑似 AI、垃圾内容和广告 / 软广。

获取 API Key ↗ 越低越容易标记。独立判断：AI 达标显示紫色 AI；垃圾内容显示红色 slop / 垃圾；广告或软广显示蓝色 Ad / 广告。默认 65%。

只检测当前可见推文和评论，不访问作者主页；自动屏蔽提示默认关闭。标签位于 Grok 左侧，点击可在右上角查看评分。

默认关闭。开启后仅 slop 触发，AI 或广告单独命中不弹窗。同一页面每个账号仅提示一次，提示至少间隔 30 秒。最终屏蔽由你确认。

启用后，当前可见推文和评论正文会发送至 TypeSafe AI，可能产生 API 费用。密钥仅保存在本机。文本判断可能误判，不代表作者真实创作方式。
